Your Mac,
at your fingertips.

Launch apps, work things out, find the right emoji, and run Shortcuts without leaving the keyboard.

Download for macOS Requires macOS 14+
⌥Space

Launch apps.
Hands on keys.

Press ⌥ Space from anywhere, type a few letters, then use ↑ and ↓ to choose. Press Return to open.

  1. 01Open⌥ Space
  2. 02ChooseType, then ↑ or ↓
  3. 03LaunchReturn

Calculate.
Keep your flow.

Type an expression where you launch apps. Use ↑ and ↓ to select an answer, then press Return to copy it.

Arithmetic
123 + 25% + 10%→169.125
Units
10 km to miles→6.21371 mi
Number bases
255 to hex→0xFF
Relative dates
5 days from now
Timezones
9am GMT→PDT
Currencies (optional)
100 USD to EUR

Find emoji.
Without the mouse.

Type : to enter emoji mode, search by name, and use the arrow keys to choose. Press Return to copy.

:→Type→↑ ↓→Return
✨ 🥳 🎉

Run Shortcuts.
Stay on the keyboard.

Type > to enter Shortcuts mode, search by name, and use ↑ and ↓ to choose. Press Return to run.

Less pointing.
More doing.
